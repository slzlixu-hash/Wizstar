# 设计规范 · AgentWorkBench Desktop UI

> 本文件描述 WorkBenchUI 的视觉语言与布局规则。所有页面都应遵循同一套令牌与组件，
> 新增页面时先读 [CONTRACT.md](CONTRACT.md)，再对照本文件的尺度与动效约定。

## 1. 设计基调

- **深空指挥中心**：近黑的靛蓝底色 + 极光渐变 + 细网格，信息密度高但不刺眼。
- **玻璃卡片**：半透明深色卡面、1px 冷色描边、顶部微高光，不使用重投影。
- **单一强调色系**：青色（cyan）主操作、蓝色（blue）次操作、紫罗兰（violet）用于创意/分析类 Agent。
- **状态即颜色**：绿=就绪/在线、青=运行中、琥珀=待处理/HITL、玫瑰=异常/缺货、灰=待接入。
- **克制发光**：只在激活项、关键数字、主按钮使用光晕，避免整屏霓虹。
- 中文优先，数字与 ID 用等宽字体（`.mono` / `.num`）。

## 3. 布局骨架

```
┌──────────────────────────────────────────────────────────────┐
│ titlebar 36px（自绘，可拖拽，右侧最小化/最大化/关闭）           │
├───────────┬──────────────────────────────────────────────────┤
│ sidebar   │ main                                             │
│ 236px     │  page-header（标题 25px + 副标题 + 右侧操作区）    │
│ 品牌/导航 │  page-body（页面内容，纵向滚动）                  │
│ 服务状态  │                                                  │
└───────────┴──────────────────────────────────────────────────┘
```

- 主窗口默认 `1440 × 920`，最小 `1200 × 760`；登录窗口 `1180 × 720`（最小 `980 × 620`）。
- 页面内边距：上 `22px`、左右 `var(--page-pad-x)`、下 `28px`；页面内容首选 `.stack`（纵向 18px 间距）。
- 栅格：`.grid-2 / .grid-3 / .grid-4`，`.split-main` 为「主内容 + 360px 右侧栏」；窗口 `< 1360px` 时 4 列降 2 列、split 转单列。
- 卡片内边距：常规 `18px 20px`，`--pad-lg` 为 `22px 24px`；卡片标题 15px / 600，说明 12px / 弱色。

## 4. 组件规范（`WB.ui.*`）

| 组件 | 用法 | 视觉要点 |
| --- | --- | --- |
| `card` | 内容分组 | 玻璃渐变面 + 1px 冷描边，头部左标题右操作 |
| `statTile` | KPI 数字卡 | 标签 12px 弱色 → 数值 34px 700（`.num`）→ meta 12px；`warn:true` 转琥珀描边警示 |
| `btn` | 操作 | `primary` 青色实心、`gradient` 青紫渐变（一键动作）、`ghost` 透明描边、`outline` 冷描边、`danger` 玫瑰、`link` 文本 |
| `badge` | 状态胶囊 | 半透明底 + 同色文字，可选前导圆点 |
| `chip / tag` | 标签 | 灰蓝底 11px，用于模型名、工具名、规则数 |
| `table` | 数据表 | 表头 11px 弱色、行高 44px、行悬停提亮、首列 ID 等宽 |
| `tabs` | 页内分区 | 选中项青色文字 + 渐变下划线（设置页） |
| `segmented` | 过滤分组 | 胶囊容器内高亮块（占位页 / Agent 状态） |
| `switch / checkbox` | 开关 | 开启态青色发光轨道 |
| `drawer / modal` | 浮层 | 右侧抽屉 520px，遮罩 `rgba(3,7,15,.62)` + 背景模糊 |
| `terminal` | 调试输出 | 近黑底、等宽 12px、JSON 键青/值绿/数字琥珀 |
| `toast` | 轻提示 | 顶部居中（或右下），2.6s 自动消失，成功绿/信息青/警告琥珀 |

图标统一走 `WB.icon(name, size, cls)`（内联 SVG，stroke 1.7，24×24 视框）；
品牌标识走 `WB.brandLogo(size)`（渐变圆角方块 + 六边形 + 竖线节点）。

## 5. 动效

- 页面进入：`.fade-up`（`translateY(8px)` → 0，`320ms`，`cubic-bezier(.2,.7,.2,1)`），
  同屏元素按 45ms 递增延迟，最多 260ms。
- 抽屉：`slide-in-right 320ms`；遮罩淡入 200ms。
- 运行状态点：`pulse` 2s 无限（仅在线/运行中）。
- 数据流/管线：`flow` 虚线位移动画 1.4s 线性无限。
- 悬浮：卡片 `translateY(-2px)` + 描边转青（120ms）；按钮亮度提升。
- 所有动画控制在 150–350ms，不使用弹跳曲线。

## 7. 约束

- 无第三方 UI 库、无构建链、无网络请求；所有图形用内联 SVG / CSS 渐变实现。
- 演示数据集中在 `renderer/js/mock-data.js`，页面不得自行硬编码业务数字。
- 交互仅限本地演示：切页、切 tab、过滤、开关、toast、抽屉、模拟登录。
